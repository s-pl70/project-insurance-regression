# Predicting Medical Insurance Charges

Multiple linear regression project for Module 6: Data Modelling, Prediction, and Inference.

**Goal:** Predict yearly medical insurance charges from age, BMI, children, sex, smoking status, and region.

**Result:** The final model reached R² = 0.91 and RMSE ≈ $4,158 on the test set. Smoking, especially combined with obesity, was the biggest driver of cost.

**Files**
- `insurance_regression.ipynb`: data cleaning, exploration, regression, and evaluation
- `insurance.csv`: dataset (Lantz, 2013), from github.com/stedy/Machine-Learning-with-R-datasets

**Tools:** Python, pandas, matplotlib, seaborn, scikit-learn, statsmodels
